## ⚡ Cách Chạy Nhanh Nhất

### **Bước 1:** Tải tất cả file
- ✅ `index.html` (Trang chủ)
- ✅ `products.html` (Sản phẩm)
- ✅ `equipment.html` (Thiết bị)

- ✅ `script.js` (Interactivity)

### **Bước 2:** Đặt tất cả file vào 1 folder

```

├── index.html

└── script.js
```

## 📝 Cách Chỉnh Sửa

### Sửa Nội Dung (Text)
1. Mở file HTML bằng Notepad
2. Tìm text cần sửa (Ctrl+F)
3. Sửa nội dung
4. Lưu file (Ctrl+S)
5. Refresh browser (F5)

### Sửa Màu Sắc
1. Mở file `style.css`
2. Tìm mã màu (ví dụ: `#1960a3`)
3. Thay bằng màu mới
4. Lưu và refresh

### Thêm Sản Phẩm
1. Copy/paste phần product-card trong `products.html`
2. Sửa thông tin (tên, ảnh, mô tả)
3. Lưu và refresh
